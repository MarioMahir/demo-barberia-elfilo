# Barbería El Filo — demo

Landing de demostración de una barbería **ficticia** en Los Prados, Santo Domingo. Muestra de trabajo; no es un negocio real.

HTML, CSS y JS vanilla. Se despliega en Render como **Static Site** con Publish Directory en la raíz del repo.

Tras el primer despliegue, actualizar en `index.html` las URLs absolutas de `og:url` y `og:image` con el dominio real.
